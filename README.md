# Soulgame · 先玩游戏，再交朋友

可点击的高保真手机原型（纯 HTML + CSS + JS，无需构建），用浏览器直接打开 `index.html` 即可体验。

在线体验：https://suda-go.github.io/play-zone-prototype/

## 产品思路

先让用户玩游戏，再通过游戏沉淀社交关系。只做一款游戏（演示用四子棋），参考 Yalla Ludo 的金币分场和"对局 → 加好友 → 私聊约局"链路。

## V2 内容

- **单游戏大厅**：打开即是四子棋主页，包括主视觉、段位卡、金币分场、和好友玩 / 创建房间 / 人机练习，没有游戏列表和选游戏的步骤
- **金币分场**：新手场100 / 进阶场500 / 高手场2000 / 大师场10000（按等级解锁）。入场扣底注，赢家拿走奖池（底注×2），平局退还，取消匹配全额退还
- **好友房**：不扣金币、不计段位、不加经验，只管和朋友玩；高级房需要房卡
- **结算页社交位**：和真人打完，直接"加好友"或"再战TA"（同一对手、同一场次）
- **最近一起玩**：消息 → 好友页列出最近对局过的人，一键加好友；加了一起玩过的人计入任务
- **局内语音**：对局页的麦克风、扬声器开关，第一次开麦弹授权，头像上显示说话声波（演示，不接真实语音）
- **钻石**：任务、签到、会员发放，可在商城兑换金币
- 签到与任务、商城、排行榜、赛季、背包、徽章、设置等沿用 V1

只有四子棋可以完整试玩。

## 演示小工具
