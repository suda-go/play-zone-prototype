# Soulgame, play with your soulmates.

可点击的高保真手机原型（纯 HTML + CSS + JS，无需构建），用浏览器直接打开 `index.html` 即可体验。

在线体验：https://suda-go.github.io/play-zone-prototype/

## 产品思路

先让用户玩游戏，再通过游戏沉淀社交关系。只做一款游戏（演示用四子棋），参考 Yalla Ludo 的金币分场和"对局 → 加好友 → 私聊约局"链路。

## V5 内容

- **新 Slogan**：Soulgame, play with your soulmates.（登录页、网页标题）
- **对局中加好友**：对局里点对手头像，弹出资料卡（等级、签名、对局数、胜率、段位、和你玩过几局），可以直接加好友；还不是好友时头像右下角有个“+”。看资料时对局照常进行，计时不暂停；人机对手的头像不能点
- **亲密度和一起养宠物**（演示用的静态展示，没有计算和交互）：好友私聊顶部显示亲密度等级（初识 → 熟络 → 好朋友 → 挚友 → 灵魂伴侣）和进度，说明聊天、一起下棋、通话都能涨亲密度；和莉莉的私聊里还有两个人一起养的宠物“豆豆”（占位示意图）
- **默认头像和昵称**：游客和邮箱注册的新账号默认昵称 happy、默认头像是卡通宝宝；Google / Facebook 登录仍用第三方账号的昵称和头像
- **演示数据单独存放**：和同一域名下 V3、V4 的预览互不影响

## V4 内容

- **登录**：打开 app 先登录。可以用 Google、Facebook 账号登录（模拟授权页，不接真实 SDK），可以用邮箱注册（验证码，演示里用一条新邮件通知送达，点一下自动填入）和登录，也可以选游客模式直接进入。同一账号再登录进度还在，换别的账号从新用户开始
- **账号管理**：设置页显示当前账号，可以退出登录；游客在我的页、设置页可以绑定 Google / Facebook / 邮箱，进度保留；游客退出前提示数据会清空
- **首页精简**：参考 Yalla Ludo，一屏放下不用滚动。从上到下是段位和好友排名两张小卡片、四子棋标志、五个玩法入口（快速开始、和好友玩、人机练习、创建房间、超级会员场）。快速开始点一下就匹配，金币分场收进“换场次”弹层；金币不够上次的场次时自动换成能进的场次
- **新手引导**：领完新手礼包只引导“快速开始”，签到引导挪到打完第一局之后
- **修复**：第二次匹配起，匹配页一进来就显示“加载中”；悬浮窗不再盖在弹层上面

## V3 内容

- **悬浮窗**：首页的回合制卡片改成右下角悬浮窗，提示下一步（轮到你了 / 等对方落子），可拖动吸边、可收起
- **对局缩小**：对局中点左上角或按返回，对局缩小成悬浮窗，计时和对手照常进行，点悬浮窗回到对局；缩小期间连续2次超时判负；认输改到右上角旗子
- **赛季模块**：首页突出展示赛季名、倒计时、我的段位进度、段位奖励轨道和好友排名
- **两档会员**：会员 $4.99/月、超级会员 $14.99/月，会员中心按对局 / 社交 / 身份 / 成长四组展示权益，带对比表、每日福利；权益实际生效（每日金币、破产补助、段位保护卡、经验加成、高级房免房卡、超级会员场、名字颜色、入场特效、访客）
- **语音 / 视频通话**：私聊页和好友主页可发起通话；会员语音免费，超级会员视频免费，否则按次付钻石（语音20、视频50）；通话记录写回聊天；会模拟一次好友来电

## V2 内容

- **单游戏大厅**：打开即是四子棋主页，包括主视觉、段位卡、金币分场、和好友玩 / 创建房间 / 人机练习，没有游戏列表和选游戏的步骤
- **金币分场**：新手场100 / 进阶场500 / 高手场2000 / 大师场10000（按等级解锁）。入场扣底注，赢家拿走奖池（底注×2），平局退还，取消匹配全额退还
- **好友房**：不扣金币、不计段位、不加经验，只管和朋友玩；高级房需要房卡
- **结算页社交位**：和真人打完，直接"加好友"或"再战TA"（同一对手、同一场次）
- **最近一起玩**：消息 → 好友页列出最近对局过的人，一键加好友；加了一起玩过的人计入任务
- **局内语音**：对局页的麦克风、扬声器开关，第一次开麦弹授权，头像上显示说话声波（演示，不接真实语音）
- **钻石**：任务、签到、会员发放，可在商城兑换金币
- 签到与任务、商城、排行榜、赛季、背包、徽章、设置等沿用 V1

只有四子棋可以完整试玩。
