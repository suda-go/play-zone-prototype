# 畅玩空间 · 互动游戏频道原型

可点击的高保真手机原型（纯 HTML + CSS + JS，无需构建），用浏览器直接打开 `index.html` 即可体验。

## V1 内容

- **启动**：打开即进入游戏大厅，首次进入领取新手礼包（100钻石 + 500金币 + 1张加速卡）
- **大厅**：赛季横幅、回合制对局、在线好友、分类推荐游戏；顶栏签到按钮进入任务列表，旁边是商城入口
- **对局**：详情 → 玩法说明 → 匹配（快速 / 极速 / 加速卡 / 取消退还）→ 四子棋 → 结算（胜负 / 段位保护 / 投降）
- **成长**：7日签到、每日 / 每周 / 新手 / 限时任务、神秘任务、连续7天宝箱、排行榜、赛季海报
- **商城**：装扮、道具、小米钱包充值、看广告领奖、会员订阅
- **社交与房间**：快速加入、高级房、创建房间、邀请好友、私聊、好友申请、新建群聊、他人主页
- **我的**：编辑资料、钱包明细、背包、战绩、徽章、设置

只有四子棋可以完整试玩，其他游戏是占位页。

## 演示小工具

我的 → 设置 → 最下方：跳到下一天、钻石清零、重置演示。地址栏加 `#页面ID`（如 `#tasks`、`#shop`）可直接打开对应页面，Esc 等同安卓返回键。
