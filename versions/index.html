Soulgame 原型 · 历史版本

每个版本都是独立快照，可以分别打开对比。手机或电脑浏览器均可。

V1

畅玩空间 · 互动游戏频道多款游戏

  • 打开即进游戏大厅（去掉游戏中心入口），21 款游戏 + 分类推荐，四子棋可完整试玩
  • 签到与任务合并：顶栏签到按钮进入任务列表，顶部是 7 日签到；旁边是商城入口
  • 每局消耗钻石入场；房间、聊天、个人中心、商城、排行榜等完整功能
  • 界面全部中文化
打开 V1版本说明
V2

Soulgame · 单游戏 + 金币分场先玩游戏，再交朋友

  • 改名 Soulgame；只保留四子棋，去掉所有选游戏环节，首页就是这款游戏
  • 参考 Yalla Ludo 的金币分场：新手 / 进阶 / 高手 / 大师场，赢家拿走奖池
  • 好友房免费、不计段位；结算页"加好友 / 再战TA"；消息页"最近一起玩"
  • 局内语音开关（演示）
打开 V2版本说明
V3

悬浮窗 · 两档会员 · 通话主站当前版本

  • 回合制提醒改为右下角悬浮窗；对局可缩小到悬浮窗、后台继续，点击回到对局
  • 首页突出赛季模块：段位进度、段位奖励轨道、好友排名
  • 会员 / 超级会员两档：每日金币、破产补助、段位保护卡、超级会员场、访客、入场特效等
  • 私聊语音 / 视频通话（会员免费或按次付钻石），含好友来电
打开 V3版本说明
V4

登录 · 首页一屏当前最新

  • 新增登录：Google / Facebook / 邮箱注册与登录 / 游客模式，游客之后可绑定账号
  • 首页精简成一屏："快速开始"一点就匹配，场次收进"换场次"弹层
  • 修复：悬浮窗不再盖住弹层；第二次匹配起匹配页一进来就显示"加载中"
  • 演示邮箱账号：demo@soulgame.com，密码 soul2026（也可直接游客进入）
